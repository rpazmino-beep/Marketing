# Brief pendiente: Folleto de negocio/servicio propio

Estado: **pendiente** — a la espera de retomar en una conversación con el
conector de Canva activado.

## Ya definido

- **Tipo de folleto:** promoción de un negocio/servicio propio.
- **Herramienta a usar:** Canva, con imágenes.
- **Motivo de la pausa:** el conector de Canva no tenía sus herramientas
  cargadas en la sesión de chat donde se inició este pedido (estaba
  autorizado a nivel de cuenta, pero no activado para esa conversación
  concreta). Las herramientas de un conector se fijan al abrir la sesión,
  así que hace falta una conversación nueva con Canva ya activado.

## Pendiente por definir (recopilar antes de retomar)

- Nombre del negocio y a qué se dedica (rubro/servicios).
- Público objetivo.
- Datos de contacto a incluir (teléfono, web, redes, dirección).
- Colores/logo o estilo de marca (si ya existe uno).
- Tamaño/formato del folleto (tríptico, media carta, etc.).
- Imágenes o material gráfico ya disponible para usar.

## Cómo retomar

1. Abrir un chat **nuevo** en claude.ai con el conector **Canva** activado
   para esa conversación (icono de conectores junto al campo de mensaje).
2. Compartir el contexto del negocio (o referenciar este archivo).
3. Verificar las funciones reales de Canva expuestas en esa sesión y usarlas
   para crear el folleto.
